# 多选与导出格式

## 使用步骤

1. 在“素材 → 存储卡”读取照片。
2. 长按一张照片，或点击右上角“选择”，进入多选。
3. 点击照片勾选或取消，支持全选当前筛选结果。搜索不会丢掉已勾选的其他照片。
4. 底部显示目标格式、文件数量、源数据大小，以及需要本地转换或跳过的数量。
5. 点击“导出”。在“已导出 / 队列”查看结果、分享文件或保存到系统照片。

默认格式为“全部原文件”。在“相机 → 照片导出 → 导出格式”修改；多选栏也有设置入口。偏好会保存，已创建的任务保留创建时的格式，不随之后的设置变化。

## 格式规则

| 设置 | 相机已有文件 | 导出行为 |
|---|---|---|
| 全部原文件 | RAW、JPEG、HEIF、视频或关联文件 | 保留该组所有可下载文件，字节不变 |
| RAW（ARW） | 有 ARW | 导出 ARW 原文件 |
| RAW（ARW） | 没有 ARW | 显示跳过数量，不把 JPEG 伪装为 RAW |
| JPEG（JPG） | 有 JPEG | 优先下载机身 JPEG，字节不变 |
| JPEG（JPG） | 只有 RAW / HEIF / TIFF / PNG | 下载原文件，在 iPhone 转为全尺寸 JPEG |
| JPEG（JPG） | 视频 | 跳过；视频使用“全部原文件” |

JPEG 转换使用 Apple 原生 Core Image / RAW 解码，输出 sRGB、质量 95% 的 JPEG。导出保留完整像素尺寸，不使用相册的 1920×1080 预览或显示时的 4096 像素上限。RAW 不受系统支持时报告失败，不降级成内嵌预览冒充全尺寸导出。原始下载文件保留，便于放大查看和再次导出。

保留可用的拍摄日期、曝光信息和 GPS 元数据，重新写入输出尺寸与正常方向。RAW 的本地显影颜色可能与机身 JPEG 不同。

## 队列与恢复

计划先写入 `Documents/Exports/.queue.json`，再开始下载。每项绑定相机内容、文件编号及完整文件身份；同一文件和同一目标格式不会重复建任务。已有本地原文件时直接复用。

下载沿用已确认分段的续传逻辑。转换串行执行，先写临时文件，完成后再原子替换结果。进入后台或断开时暂停；重启后，未完成任务显示为暂停，可从队列继续。当前批次的已完成项目会保留，恢复不会把进度分母改成剩余数量。

暂停下载会等待当前分段确认；转换已经开始时会完成当前文件后停止后续项目。失败保留源文件和剩余任务，不标成成功。用户在“文件”中移除了已有导出文件后，再次明确导出可重新下载；不会覆盖被用户改过的现存原文件。
