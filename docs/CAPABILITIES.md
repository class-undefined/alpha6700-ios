# 功能与验证表

## 状态口径

“已实现”表示存在协议桥接和 App 入口。“手机已实测”表示本次在 iPhone 上连接现场 α6700 后验证过。“上游已验证”仅指 alpha2go 作者的测试，不替代我们的手机验收。

范围是 α6700 在当前模式下开放的 PTP 3.00 能力。机身返回 350 项属性；扩展握手还会声明更多属性与控制代码。属性是否可写、可选值和范围每次都读取机身，不由静态名称表决定。

## 不覆盖的功能

- 未知控制代码：没有可靠的数据类型或语义时只展示声明，不任意发送。
- 蓝牙配对、蓝牙唤醒、自动加入热点：仍属后续工作。
- 相机拒绝的接口：alpha2go 在 α6700 固件 2.00 上记录镜头信息、FTP 设置列表、变焦 / 对焦预设、视频回放等接口被拒绝。名称相近的“FTP 配置名称读取”是另一个接口。
- 后台永久保持连接和无人值守批量导入：当前不做承诺，系统挂起时转为可恢复的前台任务。
- 大于 4 GiB 的真实视频：位宽与偏移逻辑有测试，实际文件仍需现场验证。
- 相机监视流、USB 连接、所有型号兼容性：不在当前交付范围内。
