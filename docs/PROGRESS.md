# 开发进度

## 目标与范围

在 iPhone 上运行 α6700 遥控 App。SwiftUI 使用 iOS 26 原生 Liquid Glass。通过 Personal Team 开发签名安装，每 7 天重新签名。复用已验证的 alpha2go 协议，编译为 App 内的原生库；手机直接连接相机。

“全部功能”以当前协议和机身实际开放的能力为边界。覆盖全部可读取属性、相机允许写入的属性、已知控制项和管理接口。相机菜单中的所有功能不一定有远程接口，不能将声明支持或上游测试当作本机验证。

## 设计决定

- 原生 SwiftUI 前端调用 Go 编译的静态库，SSH 和 PTP 在手机进程内执行。
- 相机指纹必须核对；认证信息存入 iOS Keychain。公开仓库排除原始证据、影像、签名文件和本机配置。
- 读取能力后生成参数界面。每次写入重新读取约束，写后读回。
- 快门、录像切换、删除、恢复设置和 LUT 上传不自动重放。
- 传输只保存相机已确认的分段偏移，重连核对文件身份。
- 免费签名优先使用同一局域网和手填地址。多播发现和自动加入热点有额外 entitlement 限制。
- UI 参考 Apple Liquid Glass 文档和 pchelnikov/Liquid-Glass-Examples 的组合方式，自行编写界面。
